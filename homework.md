# Linus's Homework

## 1. What is 2 + 2?

4

## 2. What is JavaScript?

JavaScript is a high-level, dynamic programming language that is primarily used to make web pages interactive and dynamic.

## 3. What three problems does Git & GitHub solve?

Git and GitHub solve problems of tracking code changes, collaborating safely with others, and storing projects securely online for backup and sharing.

## 4. What happens when you `fork` a repository?

When you fork a repository, you create your own copy of someone else’s project on your GitHub account, so you can freely modify it without affecting the original.

## 5. What happens when you clone a repository?

When you clone a repository, you download a full copy of it from GitHub to your local computer, including all files, branches, and history, so you can work on it offline.

## 6. What is a Pull Request?

A Pull Request is a request to merge your changes from one branch or fork into another repository, allowing others to review, discuss, and approve your code before it becomes part of the main project.
